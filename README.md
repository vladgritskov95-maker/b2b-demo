# Bereke B2B — демо

Одностраничное демо биржи закупок. Весь код в `index.html`, внешних зависимостей нет,
сборка не нужна — это обычная статическая страница.

## Как выложить

1. Создать репозиторий на GitHub, залить туда `index.html` (можно прямо через кнопку
   «Add file» → «Upload files» в браузере, без git).
2. На vercel.com → **Add New** → **Project** → выбрать этот репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставить пустыми.
4. **Deploy**. Через полминуты получится адрес вида `имя-проекта.vercel.app`.

Дальше любое изменение `index.html` в репозитории Vercel подхватит и выложит сам.

## Статистика посещений

В проекте Vercel → вкладка **Analytics** → включить. Будет видно, сколько человек
открыли страницу и с каких устройств.

## Что внутри демо

Заказчик: публикация заявки (разбор текста или ручной ввод), предложения поставщиков,
проверка контрагента, распределение объёма между поставщиками, оформление сделки,
этапы приёмки, документы, каталог спроса.

Поставщик: подобранные заявки с метками совпадения, отправка предложения, отгрузка.
